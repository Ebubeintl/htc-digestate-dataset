# Supplementary data: HTC-assisted dewatering of cattle manure digestate

Supplementary material for the article "Hydrothermal carbonization-assisted dewatering of cattle manure digestate: compression mechanisms and phosphorus and potassium partitioning for integrated valorization" (Waste and Biomass Valorization, submitted).

Authors: Ebube Daniel Ezeokolie, Teemu Kinnarinen, Kristian Melin (LUT University, Finland)
Contact: ebubedaniel04@gmail.com

## Files
- ESM_1.pdf (Online Resource 1): central composite design matrix with all responses, response surface model statistics, step-end piston-press data, point EDS compositions, TOC/TN analysis sequence, response surface plots, SEM micrographs and full-range FTIR spectra.
- ESM_2.xlsx (Online Resource 2): processed dataset (press results and step data, HTC design responses, raw-digestate controls, EDS points, TOC/TN sequence, FTIR spectra). See its README sheet.
